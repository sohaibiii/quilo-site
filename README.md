## Editing

Page text lives in `_src/` (one file per page). The header, footer and support email are in `tools/build.py`.
After a change, run `python3 tools/build.py` from the repo root and commit the generated `index.html` files.

If the app adds or removes an AI service, update the privacy policy, the in-app permission sheet and the Settings footer together.
